# .github

Org-wide default issue templates for HeHe-Corp: GitHub applies them to every repository of the org that has no
`.github/ISSUE_TEMPLATE/` of its own. Public because GitHub requires it; holds no code and no secrets.

- `.github/ISSUE_TEMPLATE/`: `task`, `bug`, `spike`, and `config.yml` (no blank issues).

How the templates are used (roles, sizing, hand-offs): the `factory` repository.
